Proyecto Residencia Itá Pytã Punta

Proyecto residencial implantado en el histórico barrio Itá Pytã Punta de Asunción, sobre la calle Guillermo Arias, caracterizado por su pronunciado desnivel topográfico hacia el Río Paraguay y visuales panorámicas hacia el atardecer.

Superficie del Lote:
306.59 m² (9.89m frente x 31.00m fondo)
Desnivel Natural:
3.64 metros desde calle (+100m) a fondo (+96.20m)
Estado Estructural:
Zapatas Z1..Z20 y pilares ejecutados al 100%
Galería Panorámica:
3.50m x 9.55m con vista al río y parrilla

Planos Arquitectónicos y Geotécnicos (Vectoriales)

Estudio Geotécnico Nº 2956 • GEO-STAN S.R.L.

Se ejecutaron 3 sondeos de penetración estándar (SPT) hasta 10.05m de profundidad, con nivelación óptica referida a cota +100.00m.

Sondeo Ubicación Cota Boca Prof. Estrato Superior Rechazo SPT (>50)
S-1 Frente (Jardín) +99.84 m 10.05 m Arena limosa SM (Nspt 16-20) 5.00 m (Arenisca)
S-2 Centro (Vivienda) +97.15 m 10.04 m Arena limosa SM (Nspt 11-18) 5.00 m (Arenisca)
S-3 Fondo (Barranco) +96.20 m 10.05 m Relleno + Arena SM (Nspt 7-12) 4.50 m (Arenisca)
Conclusión Geotécnica: Terreno altamente portante y libre de nivel freático. Las zapatas directas a 1.20m de profundidad sobre suelo SM tienen capacidad portante admisible de 10.0 a 17.9 Tn/m², garantizando absoluta estabilidad sin asentamientos diferenciales.

¿Cómo seguir el proyecto desde el celular cuando apagues la laptop?

  1. El sitio web está desplegado en una URL pública y segura (ej: https://itapytapunta.web.app o Cloudflare Pages).
  2. Abre el enlace en Google Chrome o Safari desde tu teléfono móvil. Funciona con gestos táctiles fluidos (1 dedo para rotar, 2 dedos para zoom y paneo).
  3. Si realizas cambios en el código o deseas agregar fotos, un simple git push en GitHub dispara el despliegue automático mediante GitHub Actions sin encender tu laptop.
git remote add origin https://github.com/leoberniga/itapytapunta-3d.git
